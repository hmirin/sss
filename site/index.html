Use your own server.

Connect to an existing instance with an environment variable, or pass --upstream to a command.

export SSS_UPSTREAM=https://your-server
sss new --name hello

Add authentication when needed.

Start without authentication. Set shared Basic credentials and override viewing or editing access per project.

export SSS_BASIC_AUTH='user:password'
sss serve
Use HTTPS when transmitting credentials over a network.
