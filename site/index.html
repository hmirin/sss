Read the installation instructions ↗

Every update has an address.

Share the latest site or keep a link to a specific version. Roll back when you need to.

/s/a1b2c3/Current

/s/a1b2c3/versions/1/Version 1

/s/a1b2c3/versions/2/Version 2

Remote Deploy

Connect to your server with SSS_UPSTREAM, or pass --upstream to a command.

export SSS_UPSTREAM=https://your-server
sss new --name hello
sss sync ./public --project a1b2c3

Authentication

Start without authentication. Set shared Basic credentials and override viewing or editing access per project.

export SSS_BASIC_AUTH='user:password'
sss serve
